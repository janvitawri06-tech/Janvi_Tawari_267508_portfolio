# Janvi Tawari — Digital Marketing & Tech Portfolio

A modern, responsive personal portfolio showcasing a blend of **Digital Marketing, Social Media Content Creation, and Software/AI Engineering**. Built as a B.Tech AIML student profile.


## 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3 (Custom Grid, Variables, Keyframe Animations), JavaScript
* **Design & Concepts:** Design Thinking, Responsive Mobile-First Architecture, Dark/Light Mode Support
